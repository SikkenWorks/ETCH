ETCH HELP

HOME: PLAY, HOME+SAVE: PROJECTS. HOME+FX: GROUPS. HOME+ARP: PERFORMANCE. EDIT: draw wave. SAVE: save selected object. LFO: modulation pages. ENV: envelopes. FX: effects. SEQ: grid and pattern. ARP: arpeggiator. GLO: system. Knobs K1–K4 edit the four displayed values.

Keyboard: A W S E D F T G Y H U J K · arrows in DRAW · Escape = PANIC · OCT+ / OCT− change keyboard octave. Group capture works with hardware keys or USB MIDI in this simulator. SAVE PROJECT stores group ranges and preset references. Turn groups OFF to use the main patch everywhere. MOD MATRIX 2.0: K1 route K2 source K3 target K4 signed depth; sources include channel aftertouch and keytracking. Save your project to preserve routes.

PERFORMANCE · V1.46

Open PERFORMANCE above or use HOME+ARP on the FM1. Four assignable macros and two project-scoped snapshots. On the FM1: SELECT switches ASSIGN mode, ALGORITHM selects A/B, REC captures and PLAY recalls. SAVE PROJECT preserves the snapshots.

MOD MATRIX 2.0
