# ETCH V1.48.5 — New native firmware / B1 HF2 installer

This iteration is a **new native FM1 app compilation**, not merely an updated installer or renamed old `.fwsc`.

- Native application ID: `FM-1_1485` (was `FM-1_1048`).
- Storage and OTA writes compiled in; project format remains PJT31.
- No new synth/DSP functionality in this version. The intentionally limited change is a newly identified and packaged firmware application compatible with the current installer.
- The two `.fwsc` variants contain **the same newly compiled app** with a different pinned, preserved 16 KiB protected boot-header family: legacy ETCH and original V15.
- The bundled installer uses the B1 HF2 two-stage MIDI handoff logic for the `ota-FM-1_9xx` family as well as `ota-FM-1_015`, and verifies the firmware with SHA-256.
- The OTA loader binary is unchanged from the verified V1.48 reference package.
- Neither cross-firmware physical installation nor independent hardware recovery has been verified here. Success in a simulator is not a guarantee that your installed firmware accepts an update.

## Files

- `release/ETCH-FM1-V1.48.5-ETCH-HEAD.fwsc`
- `release/ETCH-FM1-V1.48.5-STOCK-HEAD.fwsc`
- `WebInstaller.html` (embeds both new variants)
- `tools/build_v1485_firmware.py` (reproducible package generator; depends on the two protected-header V1.48 references and the compiled app)
- `tests/test_v1485_firmware.mjs` (protocol and embedded-binary parity regression)

## Install safety

Keep verified backups. On an FM1 already running an older ETCH revision with original V15 boot header or Felucca/SLOOP, prefer the V15 variant selected automatically by the WebInstaller. A device-side OTA CHECK must approve the transfer before WRITE. If the loader transition fails, stop and save the diagnostic log. Never force a flash into an unknown loader.
