# ETCH V1.72 — screen preservation and string-ensemble stability audit

**29 October 2026. Software-tested release candidate, NOT verified on physical FM1.**

## Screen preservation

- All **62 V1.71 numeric screen IDs (0–61)** are unchanged. No source `.c` or `.h` file was removed from V1.71.
- SIMPLE remains SOUND / MORPH / FILTER / FX / LIBRARY.
- ADVANCED screen catalog: from SIMPLE press GLO, K2 choose ADVANCED; K3 selects 1–62, K4 opens the selected screen. Navigation wraps both directions. Existing physical shortcuts still operate.
- MONO-only pages are explicitly unavailable while in POLY. No silent voice-mode changes when browsing.
- Entry to NAME and PROJECT SAVE now uses the **existing safe initializer** rather than landing in a stale screen state. PRESETS and PROJECTS also initialize their cursor/browser states. Save and erase still require the original confirmation flows.
- Header/cell bounds and K4 240-pixel fix from V1.71 are preserved. The added WORKFLOW status has separate rows at y=91,110,129,149,169,182, with no overlap with the parameter footer starting at y=196.
- The 62-page catalog test is a static/control-route test, not exhaustive physical pixel capture for each dynamic state. **Do not claim every screen is pixel-perfect yet.**

## STRING ENS

- The original 16 named factory starting sounds and 16 factory wave slots are preserved. New factory preset at slot 17 replaces only the first old anonymous **ETCH 16** placeholder in newly initialized banks.
- Existing stored presets are never automatically overwritten or migrated; on an existing project the WORKFLOW page supports **K1 twice** to audition an equivalent sound in the working sound state without touching flash or preset memory. Active voices must finish before preview can rebuild wave tables. Explicit SAVE is needed for persistence.
- Saw-like plus compound harmonic carrier (existing factory waveform algorithms), 38% morph, no phase modulation, attack 320 ms, release 1450 ms, LP filter 6200, chorus about 40%, modest reverb, no delay/drive. Audition uses deeper chorus modulation from the existing stereo two-tap effects engine.
- **Not** an exact Eminent/ARP Solina circuit emulation: no hardware divide-down, no original three BBD delay line circuit, no extra voice/effect buffers. Sonic resemblance requires listening on the actual FM1.

## Source compatibility

- 278 previously existing C and header files preserved; changed core files: `bringup.c`, `native_ui_navigation.h`, `native_factory.c`, `native_factory.h`. One existing factory regression test updated.
- `audio_core.c`, `native_project_codec.c`, `ota.c` are byte-identical to V1.71.
- PJT31 project format and `FM-1_1500` USB / SysEx / `.fwsc` package identity retained.
- Original protected 16 KiB ETCH bootheader and OTA loader checked against pinned V1.60 package during packaging.

## Static memory (UAC48 build)

- `.bss` 94,204 bytes, with 96 bytes `.data` and 4,004 bytes free in 96 KiB RAM.
- `.uac_ram` 6,604/8,192 bytes; **1,588 bytes free**.
- `.pool` 344,060/344,064 bytes; **4 bytes free**.
- `.noinit` 12,148/12,288 bytes; **140 bytes free**.
- No new DSP pool buffer and no per-sample oscillator or chorus work added. The new strings preview runs in the UI/control thread while voices are inactive. This is targeted stability protection, **not a general DSP RAM reduction**.

## Hardware release gate

No test in this environment verifies a safe firmware flash or independent restore on a physical FM1. A correctly built `.fwsc` plus successful simulated OTA is **not hardware qualification**. Before recommending this for a sole FM1, test LCD, long 44.1/48 kHz USB-audio operation, voice stress, project save/restore, a verified ROM-level rescue route and ETCH → another known compatible firmware → ETCH.
