# ETCH V1.80 — Boot Brand Underscore Removal

## Exact fix

In `firmware/fm1-native/bringup.c`, the clean (non-glitch) branch of
`etch_boot_brand_frame()` no longer draws the 160-pixel, one-pixel-high
horizontal underline at coordinates `(40, 163)`.

The `SIKKENWORKS` logo and `BORN OUT OF PASSION.` text remain untouched.
Nine RGB/VHS glitch frames, the 1000 ms clean-brand hold, watchdog feeding,
SIMPLE/ADVANCED selection, and storage takeover screens are unchanged.
The UI version marker was advanced to V180 only.
