# ETCH PHOSPHOR V1.82 Color Scheme

Full UI palette in firmware/fm1-native/native_phosphor_v182.h (RGB565 mapping).

| Deep Aubergine | `#15121C` |
| Muted Plum | `#25202D` |
| Warm Ivory | `#F2E9D8` |
| Dusty Lavender | `#A79AAE` |
| Acid Lime | `#C7F36B` |
| Electric Coral | `#FF7668` |
| Soft Lilac | `#B39AFF` |
| Powder Blue | `#82C8E8` |
| Golden Amber | `#FFC16E` |
| Muted Gray | `#77717E` |
| Signal Red | `#FF5263` |
| Dark Mauve | `#403749` |

RGB565 conversion is applied to legacy UI drawing calls for consistent backwards-compatible UI rendering. Wave A/B use coral/lilac; C modulation uses powder blue. PHOSPHOR does not change sound or project format.
