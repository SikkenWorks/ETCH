# ETCH V1.88 — Waveform Engine 3.0 — software audit

## Scope

- Source: V1.87 full source, modified for V1.88; no existing functions intentionally removed.
- New non-realtime wave shaping: tool 13 **PHASE WARP** (signed, endpoint-safe half-cycle remapping), tool 14 **HALF SYMM** (inverted or repeated second half).
- Existing 128-point waveform format and six antialiased wavetable mip levels retained. Existing V1.86 keyboard isolation and V1.87 adaptive drawing are preserved.
- No new oscillator, audio IRQ processing, wavetable bank, save codec field or audio buffer.
- Tool display: PHASE WARP/HALF SYMM names, A/B/C selection, original cyan + preview amber, SAVE applies once and adds one history checkpoint.
- README, USER_MANUAL, CHEAT-SHEET updated. README has no changelog text. Clean WebInstaller retained.

## Remaining limitations and risk

- A physical FM1 test is required to confirm actual harmonic differences, render speed, absence of clicks, thermal/audio CPU headroom and flash/recovery safety.
- Sharp waves can still be band-limited to fewer harmonics in high note ranges; V1.88 adds shaping choices, **not** unlimited high-frequency spectrum or alias-free aggressive distortion.
- Host acceptance of OTA packets is **not** proof of successful installation on a physical FM1. Preserve backups and a known working recovery route.
- The build reuses the original loader/bootstrap assets; no official stock firmware restoration is claimed.
- Browser visual test was attempted but hung in this environment; JS/HTML and embedded payload validation passed separately.
