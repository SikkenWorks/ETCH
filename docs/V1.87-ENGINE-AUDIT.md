# ETCH V1.87 — Adaptive DRAW / Audio Priority

## Scope

- Based on the full V1.86 source. No existing synthesis, storage, MIDI, preset, project, or OTA features deleted.
- DRAW UI control poll reduced from 25 ms to 20 ms.
- Waveform publication is requested only for dirty editor data during DRAW. Cursor-only and brush-only changes do not trigger synthesis.
- Adaptive minimum waveform compilation request intervals: 40 ms when audio load is healthy; 55 ms with active USB audio; 90 ms at moderate ALNK pressure; 140 ms at sustained/high deadline pressure.
- The DRAW cursor is painted before expensive wavetable regeneration on the same control iteration.
- The previous V1.86 65 ms keyboard transition guard and double-buffer-safe bank allocator are retained. No new audio allocation.

**Important:** these are program scheduling thresholds, **not hardware-measured end-to-end latency or CPU utilization**. A bank busy with an outgoing crossfade can defer publication. No claim of zero clicks or pops.
