# ETCH V1.82 — Build, UX and safety audit

## Native implementation

- Firmware base: complete ETCH V1.81 source. All 117 existing native C/H/assembly/linker paths are present.
- `firmware/fm1-native/native_phosphor_v182.h` maps legacy native UI RGB565 colors to PHOSPHOR without editing USB, OTA, flash or audio codec.
- The framebuffer's background is now Deep Aubergine; labels, grid, wave rendering, effect status and boot branding use the new palette.
- In WAVE DRAW only, long-hold EDIT for 700ms opens the English modal `CLEAR CURRENT WAVE? / START WITH A FLAT ZERO LINE` (default NO). Short EDIT retains the existing action. HOME and EDIT cancel. K1 selects; SEL confirms. YES checkpoints once and clears only the selected 128-point waveform to zero; Undo/Redo supported. No flash access.
- The 63-screen navigation, 22 FX BYPASS IDs, wave editor and `PJT31` format are preserved.

## Safety

No alteration to underlying flash map, project serializer, factory waves, bootloader, OTA updater, or USB device identity. Software validation is not hardware proof. Back up projects and ensure a verified physical recovery path before experimental flashing.
