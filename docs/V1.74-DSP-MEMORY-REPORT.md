# ETCH V1.74 – DSP performance and SRAM safety (29 October 2026)

**Status:** built and host-tested. Not physically verified on the M-VAVE FM1. No independent ROM restore test was performed.

## Confirmed changes

`firmware/fm1-native/native_fx.c` updates four low-pass/equalization coefficient products to **bounded signed 32-bit integer arithmetic**, replacing signed 64-bit multiplication with the same `/ 32768` division. This covers low and high EQ smoothing, optional high-pass smoothing, and global SPACE damping. No effects or audio controls are removed, and no persistent structures change.

Bound: values entering these LP stages are signed 16-bit samples and the LP states initialize to zero; coefficients are non-negative and below 32768. One-pole states remain in [-32768,32767]. Maximum delta magnitude is 65535, maximum coefficient is 15000, giving 983025000, strictly less than signed 32-bit max 2147483647. A `_Static_assert` enforces the product bound.

Four deterministic PCM golden hashes generated from the original V1.73 native source match V1.74: dry, wet, EQ, HPF and SPACE settings. The linked target `etch_fx_process_stereo_ex` is 4 bytes smaller in this build (V1.73 0x1854, V1.74 0x1850). This does **not** prove a real FM1 CPU speed gain.

## SRAM layout (actual linked 48 kHz UAC ELF)

| Section | Used | Region budget | Remaining |
|---|---:|---:|---:|
| `.ram_text` | 2,888 | 16,384 | 13,496 |
| `.uac_ram` | 6,604 | 8,192 | 1,588 |
| `.data` + `.bss` | 94,300 | 98,304 | 4,004 |
| `.pool` | 344,060 | 344,064 | **4** |
| `.noinit` | 12,148 | 12,288 | 140 |

V1.74 **does not recover any static SRAM**. The near-capacity `.pool` contains full-size FX delays and DSP state, three waveform banks, the canvas and project editing/storage scratch buffers. Static reservation alone does not prove a runtime leak. Unproven buffer sharing could corrupt audio, projects or OTA packages.

`tools/v174_memory_audit.py` inspects actual ELF sections, hard-coded stack guard locations, USB-audio region and section budgets against the V1.73 baseline. It aborts on static RAM growth or shifted guard addresses. It does not inspect runtime stack high-water or establish physical DMA safety.

## Tests actually executed

- JieLi pi32v2 app builds: normal, UAC 44.1 kHz and UAC 48 kHz: **PASS**.
- 19 native host cases including V1.73 PCM golden scenes, FX, audio render, polyphony, project storage, patch swaps, overload, USB-audio UAC 44.1/48 kHz and USB soak: **19/19 PASS**.
- WebInstaller host CHECK → WRITE/reconnection simulations, embedded `.fwsc` byte comparison and SHA-256: **PASS**.
- Package identity `FM-1_1500`, original protected 16 KiB boot region, pinned OTA-loader, UFW CRC: **PASS** (offline).
- Native C/header source preservation: 107 files from V1.73, 105 byte-identical, only `native_fx.c` and `bringup.c` changed; zero files deleted (see `release/V1.74-SOURCE-PRESERVATION.json`).
