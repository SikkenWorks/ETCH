# ETCH V1.70 — Native sound-first UX and stability audit

Date: 2026-10-29. Base: complete ETCH V1.61 USB audio full-source release. No hardware was connected.

## Findings from actual source

- `firmware/fm1-native/native_ui_navigation.h` defines **62 page IDs**. The daily PLAY page had three A/B/C wave IDs plus separate full-resolution numeric fields, while advanced FX started at DRIVE instead of a four-effect musical overview.
- `bringup.c` originally printed four independent knob labels at 60-pixel spacing through an unbounded `label()` that only clipped at the 240-pixel screen edge. Long captions could draw into a neighbouring label's column. Core headers were not clipped to the space reserved before the version.
- Native display animation reused the double-buffered LCD surface and 512-sample capture without allocating duplicate DSP canvases. Rendering is not real-time audio work, but frequent LCD SPI DMA updates under USB/audio load can compete for CPU and bus time.
- From the **compiled V1.70 48 kHz** ELF (`tools/check_uac_memory.py`): 4,004 B unused ordinary SRAM, 1,588 B unused UAC scratch and only **4 B** unused DSP pool. No extra static UI framebuffer was added. This is a very narrow capacity margin for any future effects.

## Exact native corrections

1. PLAY now displays **SOUND**, the current preset name and a single, true shortcut to the preset list. Its four directly editable parameters are **MORPH**, **ETCH** (Wave C depth), **TONE** (filter cutoff) and **SPACE** (reverb). Wave source details are still on MORPH/MOD/LIBRARY. This changes no DSP control value, MIDI mapping or project serialization.
2. FX first press now opens the four-knob effects overview. The existing DRIVE editor, 17 advanced FX processors and two PRE-FX slots remain reachable with further FX presses and SELECT; no effect has been disabled.
3. The title and parameter-label helper clips string glyphs within the actual labelled region. A new software layout regression asserts disjoint rectangles for the 240x240 SOUND header, identity row, hint, four labels/values and meter strips. This is a **focused** zero-overlap check, NOT proof that every one of the 62 pages is pixel perfect on a real FM1.
4. `etch_ui_refresh_budget` bounds non-urgent main-loop redraw cadence to 33 ms idle, 50 ms USB, 100 ms elevated pressure and 150 ms severe pressure. Page transitions, faults and save notifications bypass the throttle. All audio, MIDI, IRQ, storage and USB services execute independently of the LCD budget.
5. `etch_factory_seed()` now generates 16 recognisable named patches with conservative DSP settings in a blank **factory-initialised RAM bank only**. Existing populated project banks are **not overwritten**, no project format migration is performed, and the other sixteen patch slots remain available.
6. The original `FM-1_1500` package identity, OTA trusted loader and protected 16 KiB flash head are exactly preserved. One regular ETCH-V1.70.fwsc is produced; the alternate legacy head remains an installer-only compatibility option.

## Build and tests

- JieLi pi32v2 release builds: no-UAC, USB 44.1 kHz, USB 44.1/48 kHz: **compiled and FM1 application parser accepted**.
- Dual-rate application size 220,172 bytes of a 581,564-byte slot. A repeated dual-rate build produced the **same SHA-256**.
- USB 48 kHz linker allocations: `.ram_text` 2,888 / 16,384; `.uac_ram` 6,604 / 8,192; `.data` 96 and `.bss` 94,204 / 98,304; `.pool` 344,060 / 344,064; `.noinit` 12,148 / 12,288 bytes. The configured addresses did not overlap.
- Targeted host tests: factory, UI navigation, waveform UI, scope UI, USB-audio 44.1/48, USB DMA shift **6/6 passed**. Standalone compiled UI geometry and adaptive budget checks **passed**.
- The full JavaScript `npm test` suite **passed**, including the current V1.70 embedded WebInstaller binary/hash test, host DSP, sequencer, MIDI, fault injection and UI harness.
- A separate broad native run reported **17 individual PASS outcomes** including audio, FX, polyphony, overload, storage, project, MIDI, sequencing, recovery policy, before the combined run was stopped by the execution limit. The `ota` native test and remaining tasks in that run are **NOT counted as passing**. The earlier standalone V1.70 JavaScript host OTA handshake/check/transfer simulation passed; it is not real FM1 hardware evidence.
- Exact package and installer hashes: see `RELEASE-MANIFEST.json` and `tools/check_pinned_identity.py`.

## Not verified and release limitations

- No physical FM1 boot, subjective audio quality, LCD pixel screenshot inspection of every page, CPU/DMA usage measurement, long USB 48 kHz soak, external Felucca roundtrip or independent ROM-level recovery test was performed.
- The 4-byte free DSP pool and the borrowed UAC SRAM are *existing V1.61 risks*, not solved by the UX refresh. No claim of universally stable 48 kHz operation is made.
- Starter recipes may require final listening/balancing on real hardware; the original 16 waveforms and existing user presets remain untouched.
- Do **not** recommend experimental firmware flashing on an only device without a separately verified full restore path.
