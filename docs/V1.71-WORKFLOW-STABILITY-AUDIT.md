# ETCH V1.71 — Workflow, UI bounds and stability audit

Date: 2026-10-29. Baseline: full ETCH V1.70 source ZIP. Hardware tested: **NO**.

## Implemented in native FM1 firmware

1. **SIMPLE by default**: SELECT on SOUND cycles SOUND → MORPH → FILTER → FX → LIBRARY → SOUND. Direct FX/LFO/ARP entry keeps the corresponding basic editor visible; SEQ alternates its main grid and note editor.
2. **ADVANCED** restores the existing V1.70 LFO, FX, ARP, SEQ and 4-page HOME routing. All **62 existing native page IDs** are retained. No effect, synthesizer, waveform, storage, MIDI, USB, sequencer or project serialization code was removed.
3. **GLO in SIMPLE** opens SYSTEM tab 8 (WORKFLOW). K2 switches SIMPLE/ADVANCED. GLO returns to SOUND from SYSTEM in SIMPLE. All seven original diagnostics tabs remain available by SELECT. The mode defaults to SIMPLE at boot and is runtime-only, not written to PJT31.
4. **Confirmed V1.70 K4 visibility bug fixed**: `label_box` refused `right>240`, but K4's edge was calculated as **241**. The correct exclusive edge is now **240**, allowing the rightmost parameter label to render.
5. Numeric values in every generic four-cell footer now stay inside their respective cell, and overly large numbers show a visible `+` overflow indicator. Auxiliary page headers use bounded titles, preventing labels from drawing into their neighboring warning/status area.
6. Existing LCD refresh throttling (33/50/100/150 ms under pressure), USB audio allocation, DMA sample reuse and audio underrun handling are unchanged. No additional static framebuffer or audio-thread work was introduced.

No measured increase in free DSP RAM over V1.70. This is a continuing risk, and future features should not allocate in `.pool` without real memory reclamation. Builds fitting the linker map are **not proof** that the borrowed UAC SRAM behaves safely on a physical device.

- Native dedicated V1.71 workflow/geometry test and static source audit: **PASS**. Checks all 62 page title strings and their bounded header region; all four parameter cell bounds; SIMPLE/ADVANCED routing, GLO/MOD/FX/SEQ/ARP, 8 SYSTEM tabs and version/product identity.
- Original V1.70 SOUND geometry test: **PASS**, after updating its source-level current-version routing assertions.
- 16 targeted native tests with AddressSanitizer/UBSan: **16/16 PASS** (`ui_navigation`, `ui_wave`, `scope_ui`, `factory`, `usb_audio`, `usb_audio_48k`, `usb_audio_dma_shift`, `diagnostics`, `fx`, `audio`, `overload`, `project`, `store`, `poly`, `midi`, `seq_ui`). See `release/V1.71-NATIVE-TESTS.json`.
- Native OTA fault/commit regression: **1/1 PASS**. The old harness expected 20–70 reads; full UFW CRC prevalidation introduced in V1.60 now performs **2,370 reads**. The harness has been updated to expect safe rejection of internally changed but globally invalid packages rather than wrongly demanding their acceptance. The production validator was not relaxed. See `release/V1.71-NATIVE-OTA-TESTS.json`.
- Separate original ETCH package / foreign bootheader replay: **PASS** (`CROSS_OTA_RESULT=0`, `REQUESTS=2370`, `COMMITTED=1`, `BOOT_HEAD_UNCHANGED=1`, `TRUSTED_STAGED_LOADER=1`, `ota-FM-1_015`). This is a simulated host/NOR transfer, not a physical FM1 update.
- JavaScript test families for host engine, UI harness, fault injection, V1.43, V1.44 and current V1.71 installer were observed as passing; the single combined `npm test` command hit the execution time limit during the last stage. The current V1.71 installer test was rerun separately and **PASS**. Do not count the combined command as a completed pass.
- Official `.fwsc` checks: UFW CRC, expected package identity `FM-1_1500`, preserved V1.60 16 KiB ETCH head and trusted OTA loader; embedded installer package SHA-256 matching local files: **PASS**. The alternate stock header is installer-only for legacy cases, not an official stock restore.

## NOT established / release risks

- No physical M-VAVE FM1 was connected for boot, LCD screen capture, MIDI, audio load/latency, USB 44.1/48 kHz soak, cross-firmware switching, power-loss or ROM-level recovery tests.
- The full 62-screen **pixel-by-pixel** overlap-free claim is **not established**. Tests enforce all title strings and the shared footer geometry, and audit literal label bounds, but they do not exhaustively render every dynamic state, tooltip, fault overlay or translated/numeric value on the actual TFT.
- SIMPLE/ADVANCED is a **runtime preference**, deliberately not project-persisted. It always resets to SIMPLE after restart.
- DSP pool free space is still 4 bytes; no global DSP RAM optimization has been claimed. The audio priority LCD budget remains the V1.70 mechanism, not a new measured CPU saving.
- Real Felucca-family and vendor stock transitions have not been on-device tested. Only safe software-level checks are supported.

**Do not treat this candidate as safe to flash on a sole FM1 without a separately verified full restore route.**
