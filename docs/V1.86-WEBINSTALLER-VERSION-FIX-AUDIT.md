# ETCH V1.86 WebInstaller Version Fix

**Scope:** HTML installer UI and release-consistency tests; no firmware or OTA engine modifications.

## Confirmed cause

The shipped installer `ETCH-WebInstaller-V1.86.html` embedded **V1.86 binary firmware packages** with correct SHA-256 hashes, but copied the V1.85 visible and dynamically generated labels from the clean V1.85 installer. It also retained an obsolete instruction to check `V181` after the FM1 rebooted.

## Exact fix

- Updated the SikkenWorks header, current-release selection, firmware details, dynamic package selection, comments and diagnostic-log version to V1.86.
- Release description now mentions DRAW keyboard isolation (as well as the existing 128-point editor and smooth transients).
- Corrected post-OTA device-screen version check to `V186`.
- Clarified that `FM-1_1500` is the **fixed USB/package identity**, not independently verified proof of the actual ETCH version running on the device.
- Preserved the clean PHOSPHOR layout, risk acknowledgement, loader checks, OTA stages, SHA-256 checks and official stock-restore route.
- Extended `tools/check_webinstaller_ui.py` and `tests/test_v186_installer.mjs` to detect stale version labels, incorrect post-OTA display checks and firmware/package byte mismatches.
