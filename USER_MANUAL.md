# ETCH V1.37 — SEQ BOOT MIDI KEYBOARD

**New:** Hold the physical **SEQ** button (raw button 11) while powering on the M-VAVE FM1. ETCH boots into **MIDI KEYBOARD MODE**, a USB MIDI controller. The on-device synth audio/DAC DMA and PC6 analogue output remain disabled in this mode.

- All 27 FM1 piano keys transmit **USB-MIDI channel 1** Note On/Off (velocity 127) to the connected host computer. The base physical keyboard is F3–G5, MIDI notes 53–79.
- **OCT− / OCT+** shift in whole octaves, within −3…+3. Held notes send Note Off first and a retuned Note On afterwards. Octave 0 is the default every power-up.
- Device screen shows **MIDI KEYBOARD**, USB connection, octave and pressed-note count. A computer/DAW must select the existing FM1 USB MIDI input. No MIDI audio is generated by the FM1 in this mode.
- Disconnecting USB clears the local note-tracking state and stale outgoing queue entries. USB output queue backpressure retries unsent note-offs. A fresh connection resumes cleanly.
- Normal power-on runs the full ETCH synth unchanged. **REC** Safe Mode and **OCT−** independent loader boot retain priority. Power cycle without SEQ to exit keyboard mode.
- OTA upgrade transport remains serviced in MIDI keyboard mode. Project/preset storage format stays PJT27, unchanged; keyboard mode does not save projects or alter presets.
- **USB MIDI only** in this release; MIDI OUT via TRS/DIN has not been implemented/verified in this feature.

**Validation:** Native controller events, boot priority, USB note-off queue behavior, crossbuild and browser payload checks are software-tested; this build has not been tested physically on the FM1. Independent ROM restore remains unverified. MIDI keyboard mode deliberately avoids the analogue startup switch, but this does not fix the normal synth's unplugged startup pop. Historic polyphony headroom issues also remain unproven on hardware.

## V1.28 Addendum: PATCH BLEND / RIFF 2.0

### PATCH BLEND (LFO page)

After saving two sounds into named preset slots, press **LFO** repeatedly to move past MOD MATRIX into **PATCH BLEND**. The screen shows the two source slots, a blend amount and ACTIVE status.

| Encoder | Control | What it does |
|---|---|---|
| **K1** | PATCH A | Select source saved preset; skips empty slots |
| **K2** | PATCH B | Select target saved preset; skips empty slots |
| **K3** | BLEND | 0–100, transitions from A to B |
| **K4** | ACTIVE | Rotate clockwise ON / counterclockwise OFF |

You are editing the **current sound**, not the stored endpoint presets. All three waveform sample arrays, the morph and depth controls, ADSR, filter, drive and standard effect amounts are interpolated. Effect modes that cannot safely be interpolated change at the midpoint instead. The end presets remain untouched. Use normal PRESET SAVE if you want to keep a blend as its own sound. SOURCE/TARGET/MIX selections are **not** saved as a new realtime automation lane in V1.28. This is not two simultaneous synth engines crossfading their outputs.

If the screen says **SAVE PRESETS FIRST**, store at least one complete preset. For a real A-to-B blend, save two distinct sounds. Move BLEND, then enable ACTIVE. If you turn it OFF, the current sound is returned to the PATCH A endpoint as the next control change is processed.

### RIFF LAB (ARP page)

Set **ARP mode 7 (RIFF)**. Continue pressing **ARP**: **ARP → ARP EDIT → CLOCK → RIFF LAB**. This editor changes the rhythmic and melodic variation without introducing a second clock:

| Encoder | Control | Description |
|---|---|---|
| **K1** | DENSITY | Note/rest density, 0–100; default 50 preserves original riff behavior |
| **K2** | MUTATE | Amount of variation from the current motif, 0–100; 0 means no variation |
| **K3** | VARIANT | Step through motif variations while retaining the base riff |
| **K4** | NEW RIFF | Generate a new base riff |

The first beat stays anchored in the current mutation strategy. **BPM is controlled by the regular CLOCK page**, and the usual ARP rate determines note division. When external MIDI clock is enabled, RIFF follows that clock through the shared timing engine. The new settings are stored per patch slot in the **PJT25** project format. When older PJT24 projects are loaded, DENSITY resets to 50 and MUTATE/VARIANT to zero.

### Updating and startup noise

The V1.27 two-second stable USB and analog-output startup guard remains in V1.28. A louder pop after PC/USB use **could** still come from analog amplifier-enable or DC bias transients. This has not been electrically measured or physically demonstrated to be eliminated. The installer can identify previous ETCH versions including `FM-1_1026`; that is **not** a proof that flashing, booting or ROM recovery on a physical FM1 is safe. Do not flash without a verified independent recovery process.

## V1.26 Addendum: MOD MATRIX

The latest V1.26 firmware adds **MOD MATRIX** after the LIVING screen in the LFO-button cycle. It is a lightweight, four-route modulation system that changes the sound **in real time** without modifying stored waveforms. This section supersedes earlier LFO-navigation descriptions.

| Control | Function | Range |
|---|---|---|
| K1 | Route selection | 1–4 |
| K2 | Source selection | OFF / VELOCITY / ENVELOPE / WAVE C / LIVING |
| K3 | Destination | MORPH / C DEPTH / FILTER / SPACE |
| K4 | Amount | 0–100 |

**Source selection numbers:** OFF=0, VELOCITY=1, ENVELOPE=2, WAVE C=3, LIVING=4. **Destination numbers:** MORPH=1, C DEPTH=2, FILTER=3, SPACE=4. The FM1 display shows the readable names.

- **VELOCITY** is based on the note's played velocity (0–127). Louder notes can morph further, for example.
- **ENVELOPE** follows each voice's current amplitude-envelope level.
- **WAVE C** uses the actual third waveform as a bipolar modulation source, separate from ETCH's existing carrier and FX destinations.
- **LIVING** follows the per-note harmonics movement; it is only active when LIVING DEPTH is above zero.

**MORPH**, **C DEPTH** and **FILTER** are applied per voice. **SPACE** is a shared effect; its modulation follows the first active voice, not separate reverbs for every note. The modulation is intentionally bounded; full-scale positive input with AMOUNT 100 changes a destination by no more than 25% of its parameter range. Changes are additive and clamped to the destination's legal limits. Set AMOUNT to zero or SOURCE to OFF for a true bypass.

### Three examples

1. *Expressive lead:* ROUTE 1, SOURCE VELOCITY, DEST MORPH, AMOUNT 30. Harder attacks move the A/B waveform blend further.
2. *Evolving pad:* ROUTE 1, SOURCE LIVING, DEST FILTER, AMOUNT 45. Long notes slowly reveal brighter filter settings as the timbre evolves. Turn on LIVING separately.
3. *Drawn-motion texture:* ROUTE 1, SOURCE WAVE C, DEST C DEPTH, AMOUNT 20. Your third drawn waveform changes the depth of its own modulation route. Start at a low amount and listen for fast modulation sidebands.

The four routes are saved in **PJT24** alongside the other project settings. PJT23 and older projects load with MOD MATRIX disabled, preserving the original sound. V1.26 is still **software-tested experimental firmware**, not an approval to flash an FM1. There is no independently verified ROM-level recovery route or demonstrated installation on physical hardware.

## 1. Welcome to ETCH

ETCH replaces the FM1's ordinary fixed-algorithm approach with a synthesizer built around **waveforms you can draw on the instrument itself**.

The basic idea is simple:

1. Draw or load **Wave A**.
2. Draw or load **Wave B**.
3. Use **MORPH** to move between A and B as *one carrier waveform*.
4. Draw or load **Wave C** and let it modulate that carrier.
5. Shape the result using envelopes, filtering, dedicated waveform processing and effects.
6. Save the sound as a named preset, or store the individual waves for use in other sounds.

ETCH also includes a sequencer, arpeggiator with scale-aware **RIFF** generation, Wave Genetics, Wave Evolution, Motion Recording, harmony helpers and project storage.

### Three different things to save

| Item | What it is | Capacity in V1.20 |
|---|---|---:|
| **Waveform** | A reusable, named single-cycle wave in the library | 64 wave slots |
| **Preset / patch** | A named playable sound, with wave choices and sound settings | 32 preset slots |
| **Project** | A larger working state, including performance and pattern data | 4 project slots |

**These are not the same operation.** Saving a preset does not necessarily save a newly drawn waveform into the reusable waveform library. Save important waveform edits separately.

## 4. Your first sound: a guided walkthrough

This walkthrough assumes ETCH is already running normally.

### A. Start with an audible patch

1. Lower MASTER, then play a key to confirm audio is working.
2. Press **HOME** briefly to reach PLAY.
3. Turn **K1 (MORPH)** to hear the balance between the two carrier wave shapes.
4. Turn **K2 (ETCH)** to change the strength of Wave C modulation.
5. Use **K3 (FILTER/CUTOFF)** to change brightness and **K4 (SPACE)** to adjust spatial effects.
6. Raise MASTER cautiously if needed.

### B. Edit Wave A

1. Press **EDIT** to enter DRAW.
2. Rotate **SELECT** until **WAVE A** is selected.
3. Use **K1** to move across the waveform and **K2** to move the waveform vertically at the current edit location.
4. Play a note. In DRAW, the preview routes the selected wave on its own, rather than playing the full morphed patch.
5. Try **K3** to select a harmonic and **K4** to add or remove it.
6. Press **HOME** to leave editing and return to normal playback.

### C. Add another wave and morph

1. On the main screens, use **SELECT** to find **MORPH**.
2. Set Wave A and Wave B using **K1** and **K2**. Only saved library slots can be selected.
3. Hold a note and turn **K3 (MORPH)**.
4. Turn **K4** to change the Wave C modulation rate/ratio; ALGORITHM changes ETCH depth on this screen.

### D. Save the result

1. Outside DRAW, press **SAVE** to open the project/preset save editor.
2. Use the **SELECT encoder** to choose PRESET instead of PROJECT if needed.
3. Choose a slot with **K1**, move the name cursor with **K2**, edit characters with **K3** and backspace using **K4** counter-clockwise.
4. Press **SAVE** to commit, confirming again when overwriting an occupied slot.
5. To find it later, **hold HOME for 1.5 seconds**, then turn the **PRESETS encoder**.

## 5. Understanding the ETCH engine

### The signal path

```text
Wave A ── [Wave A inserts] ──┐
                            ├─> ONE MORPHED CARRIER ──> Filter / Drive ──> Global FX ──> Output
Wave B ── [Wave B inserts] ──┘              ↑
                                            │
Wave C ───────────────────────> PHASE or MORPH modulation
                                   │
                                   └─> Optional FX-parameter modulation

Wave Evolution can animate the carrier's shape without rewriting the saved waves.
ADSR and voice allocation operate alongside this signal path.
```

### A/B morphing is not a simple volume crossfade

A and B are sampled at the same oscillator phase and interpolated into a single shape:

`M(p) = (1 − m) × A(p) + m × B(p)`

Here, `m` is MORPH. At 0%, the carrier uses A. At 100%, it uses B. Between them, ETCH reshapes the waveform.

### What Wave C does

Wave C is another saved or user-drawn waveform. It can modulate the carrier's **phase** or its **morph position**. At low rates, this can introduce movement; at audio rates, it can introduce additional harmonics and more abrasive timbres.

### Polyphony and sound quality

ETCH targets **eight simultaneous voices**. The oscillators generate band-limited wave tables from editable 128-point shapes. Because the FM1 has limited CPU and RAM, dense chords with demanding FX may expose hardware-specific performance issues. V1.20 includes overload handling, but it is not a certified eight-voice stress-test result on your individual device.

## 7. DRAW: creating and editing waveforms

**DRAW is the central ETCH feature.** Each editable waveform has 128 points, later compiled into runtime oscillator tables.

### Entering DRAW

Press **EDIT**. From MORPH or LIBRARY, the active focus can determine which wave opens; otherwise ETCH remembers the previously edited wave. Use the **SELECT encoder** inside DRAW to cycle **A → B → C**.

### Actual V1.20 DRAW controls

| Control | Function |
|---|---|
| **K1** | X: move the edit position across the waveform |
| **K2** | Y: move the waveform up/down at that location, with a smooth neighbouring-point brush |
| **K3** | PART: select a harmonic/partial (2–16) |
| **K4** | HARM GAIN: add or remove the selected harmonic from the actual wave data |
| **SELECT encoder** | Choose Wave A, B or C |
| **ENV button** | Undo |
| **LFO button** | Redo |
| **FX button** | Open waveform FX / BAKE workflow |
| **SAVE button** | Open waveform save/name editor |
| **HOME** | Exit and restore the complete synth playback route |

> **V1.20 clarification:** An early ETCH concept showed K1–K4 as four directional arrows. The actual V1.20 firmware uses **K1 X, K2 Y, K3 PART and K4 HARM GAIN**. Follow the live screen labels, not the original concept drawings.

### Solo audition while editing

When you play a note in DRAW, you hear **only the currently selected waveform**. The usual A/B morph, Wave C modulation, Evolution and global effects are bypassed for this audition path. This helps you understand what you are editing. Leaving DRAW returns to the full patch **without changing its stored morph settings**.

### Undo, redo and non-destructive work

The editor maintains a **16-level** history. Undo and redo apply to edits made during the waveform session. Before a destructive action, use a spare library slot if you want to preserve the original wave.

### Saving a waveform

1. While in DRAW, press **SAVE**.
2. Select destination slot **01–64** with **K1**.
3. Set the name position with **K2** (up to 12 characters).
4. Choose a character with **K3**; turn **K4 counter-clockwise** for backspace.
5. Press **SAVE**. If an occupied slot requires confirmation, press SAVE again as prompted.
6. After a successful save, the waveform can be reused from the LIBRARY.

Saving a waveform writes to the reusable wave library; it is distinct from saving the current **preset**.

## 8. TOOLS, Wave Genetics and offline waveform FX

ETCH offers two different processing concepts:

1. **Waveform tools / offline waveform FX**, which alter the *stored or editable single-cycle shape* and can be baked into the wave.
2. **Live Wave A/B inserts and global effects**, which affect playback without rewriting the stored 128 points.

### Waveform tools

In the DRAW tool workflow, ETCH provides operations corresponding to the following source-code tool IDs:

| Tool ID | Function |
|---:|---|
| 0 | LINE: interpolate between points |
| 1 | SMOOTH: smooth the shape |
| 2 | MIRROR: mirror a portion of the wave |
| 3 | INVERT: flip polarity |
| 4 | NORMALIZE: centre and scale amplitude |
| 5 | FLATTEN: reset points to zero |
| 6 | RANDOM: generate random waveform points |
| 7 | SINE primitive |
| 8 | TRIANGLE primitive |
| 9 | SAW primitive |
| 10 | SQUARE primitive |
| 11 | PHASE ROTATE |
| 12 | WAVE GENETICS |

On the TOOLS screen, **K1** selects the operation, **K2** adjusts its span/amount, and the remaining controls serve the cursor or Genetics parameters according to the selected tool. **SAVE** applies the selected tool. The effect is reflected in the editable waveform and can be undone before you commit it to a library slot.

### Wave Genetics

Wave Genetics creates a **new Wave C** from the current A and B shapes. It does not replace the two parents.

- Set the A/B balance.
- Set the mutation amount.
- Change the seed/cursor to find other variations.
- Apply the operation, audition the generated C wave, then save it to a waveform slot if you like it.

Genetics works on the actual waveform points, so it can produce shapes that are later morphed, modified and saved like any other ETCH wave.

### WFX 1 and WFX 2: waveform-level processing

From DRAW, press **FX** to open the offline waveform FX pages.

| Page | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| **WFX 1** | DRIVE | BIT / bitcrush | CHORUS | DELAY |
| **WFX 2** | REVERB | FOLD | SMOOTH | MIX |

These controls process the currently selected waveform as a shape. The FX/TOOLS navigation lets you move between the processing pages and tools. **SAVE** is used as a two-stage **BAKE** confirmation. BAKE commits the waveform processing into editable points; save the wave afterwards if you want that result in the library.

**Important distinction:** WFX is different from the live **Wave A FX** and **Wave B FX** insert pages described later.

## 9. The waveform LIBRARY

The library stores reusable waveforms independently of presets.

### Browsing and loading

1. Use **SELECT** on the main screens to reach **LIBRARY**.
2. Turn **K1 (SLOT)** to choose a waveform slot.
3. Turn **K2 (TARGET)** to select A, B or C.
4. Press **REC twice** to confirm loading the selected valid waveform into that target.
5. Return to PLAY, MORPH or MOD to use the loaded wave.

K3 and K4 are **intentionally inactive** on the LIBRARY page. This prevents accidental selection changes while confirming a load.

### Why waveform numbers can jump

Saved waveforms occupy physical slots. ETCH may skip empty slots when using its waveform-selection helpers, so the **actual storage numbers are not always consecutive**. On some screens, the firmware also displays the ordinal position among existing waveforms. For example, “2 of 5” and “slot 25” describe different things and are not contradictory.

### Avoid overwriting shared waves accidentally

A library slot can be referenced by multiple patches. If you want a new variant, save it to another slot instead of overwriting a wave that other patches rely on.

## 10. MORPH and Wave C modulation

### MORPH page

| Control | Function |
|---|---|
| **K1** | Choose saved Wave A |
| **K2** | Choose saved Wave B |
| **K3** | MORPH position |
| **K4** | Wave C rate/ratio selection |
| **ALGORITHM encoder** | ETCH / Wave C modulation depth |

This is the quickest way to build the core sound: choose A, choose B, hold a note and move MORPH.

### MOD WAVE page

Press **LFO** until **MOD WAVE** appears.

| Control | Function |
|---|---|
| **K1** | Choose Wave C |
| **K2** | Modulation DEPTH |
| **K3** | RATE or ratio |
| **K4** | TARGET: PHASE or MORPH |
| **SELECT encoder** | Change rate mode: KEYED, FREE or TEMPO |

**PHASE** offsets the carrier's read position; **MORPH** moves its A/B blend. KEYED follows note pitch, FREE uses an independent rate and TEMPO follows musical clock settings.

### A quick modulation experiment

1. Load two noticeably different waves for A and B.
2. Set MORPH around the middle.
3. Choose a distinctly shaped C wave.
4. Try PHASE with a low depth, then raise it gradually.
5. Switch the target to MORPH and use a slower rate to hear the carrier moving between A and B.

At **zero DEPTH**, C modulation is effectively bypassed, so changing C may not produce a noticeable difference.

## 11. Envelopes, filtering and voice modes

### Amplitude envelope

Press **ENV** outside DRAW.

| Knob | Parameter |
|---|---|
| K1 | ATTACK (ms) |
| K2 | DECAY (ms) |
| K3 | SUSTAIN (%) |
| K4 | RELEASE (ms) |

A short attack and release suit plucks; longer attack/release times suit pads and evolving textures.

### FILTER page

| Knob | Parameter |
|---|---|
| K1 | Filter TYPE |
| K2 | CUTOFF |
| K3 | RESONANCE |
| K4 | DRIVE |

The filter has OFF and active modes (low-pass, band-pass and high-pass in the DSP). Changing cutoff on an OFF filter automatically engages a low-pass mode so the cutoff knob is not silent. The cutoff editor uses regular 10-unit steps.

## 12. Wave A/B inserts, Wave C FX modulation and global FX

This section is deliberately separated into **pre-morph inserts**, **Wave C-driven FX parameter changes** and **global/master effects**. They are three different jobs.

### 12.1 Live Wave A FX and Wave B FX

The FX-button workflow reaches **WAVE A FX** and **WAVE B FX** after the main global FX editors. Each wave has **two pre-morph insert slots**.

| Knob | Parameter |
|---|---|
| **K1** | SLOT 1 or 2 |
| **K2** | TYPE |
| **K3** | DEPTH |
| **K4** | MIX |

Available live insert types:

| Type | Description |
|---|---|
| OFF | No processing |
| RING | Ring-like modulation using your Wave C shape |
| BIT | Bit reduction |
| FOLD | Wavefolding |
| TREM | Tremolo-like amplitude shaping |
| LP | Low-pass smoothing/filtering |

When turning a previously OFF insert on, ETCH sets a useful default MIX if MIX was zero. An active insert that you intentionally set to **MIX 0%** stays dry.

**Solo preview:** While adjusting Wave A FX, playing a note auditions **Wave A and its own inserts only**; Wave B FX does the same for B. Return to normal performance to hear the complete A/B MORPH patch. The preview is temporary and does not rewrite MORPH.

### 12.2 Wave C FX modulation

Press **LFO** until **WAVE C FX MOD** appears. Here Wave C can change an FX parameter over time, rather than only reshaping the carrier.

| Control | Function |
|---|---|
| **K1** | FX modulation TARGET |
| **K2** | DEPTH |
| **K3** | RATE / ratio |
| **K4** | Choose Wave C |
| **SELECT encoder** | KEYED / FREE / TEMPO rate mode |

The V1.20 destination IDs are **0–31**, with 0 meaning OFF. Destinations include reverb size/decay/mix, delay time/feedback/mix, chorus rate/depth/mix, ring rate, EQ, compressor, tremolo, phaser, flanger, decimator, wavefolder, tape, reverse delay, vibrato, rotary and wah parameters.

**Tip:** Start with a slow rate and a moderate modulation depth. If the chosen effect is otherwise dry or bypassed, moving one of its internal parameters may be hard to hear until you enable the corresponding wet signal.

### 12.3 Global FX pages

Press **FX** outside DRAW to open the **DRIVE** editor. Rotate **SELECT** to move among the detailed global FX editors. The FX button also visits the Wave A/B insert pages. The currently shown page determines what K1–K4 do.

| Page | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| DRIVE | DRIVE | Filter TYPE | CUTOFF | RESO |
| CHORUS | MIX | RATE | DEPTH | ROUTE |
| DELAY | MIX | TIME | FEEDBACK | ROUTE |
| REVERSE DELAY | TIME | FEED | TONE | MIX |
| REVERB | MIX | SIZE | DECAY | ROUTE |
| RING MOD | MIX | RATE | SHAPE | BIAS |
| CHANNEL EQ | LOW | MID | HIGH | HPF |
| COMPRESSOR | THRESHOLD | RATIO | ATTACK | RELEASE |
| TREMOLO | RATE | DEPTH | SHAPE | MIX |
| VIBRATO | RATE | DEPTH | SHAPE | MIX |
| PHASER | RATE | DEPTH | FEEDBACK | MIX |
| FLANGER | RATE | DEPTH | FEEDBACK | MIX |
| DECIMATOR | BITS | RATE | DRIVE | MIX |
| WAVEFOLDER | FOLD | SYMMETRY | TONE | MIX |

| ROTARY SPEAKER | RATE | DEPTH | DRIVE | MIX |
| AUTO-WAH | SENSITIVITY | ATTACK | RESONANCE | MIX |

**ROUTE** selects the available effects routing mode (serial/parallel in the effect settings). Effect labels sometimes abbreviate parameters to fit the 240 × 240 display.

### What about SPACE?

The **SPACE** macro on PLAY and MOTION is tied to the reverb/spatial signal, while the detailed REVERB page gives you separate controls for mix, size and decay. A small SPACE setting, a dry FX mix or a very short note may make the change subtle. Start with an audible patch, then compare SPACE fully down and substantially raised.

## 13. Wave Evolution

**EVOLUTION** changes the shape of the running oscillator over time. It does **not** overwrite the saved A/B/C wave data.

Press **LFO** repeatedly to reach EVOLUTION.

| Knob | Setting | Range / options |
|---|---|---|
| **K1** | DEPTH | 0–100%, in 5% increments |
| **K2** | RATE | 0–100%, in 5% increments |
| **K3** | SHAPE | FOLD / SHARP / STAIR |
| **K4** | SYNC | FREE / TEMPO / ONE SHOT |

**REC** toggles DEPTH between **0%** and an audible **60%** starting value. The other settings stay available through their knobs.

### What each shape does

- **FOLD:** folds the waveform back on itself to create additional harmonic structure.
- **SHARP:** pushes the wave towards more pronounced edges/saturation.
- **STAIR:** applies stepped/quantised changes for deliberately gritty textures.

### Try it

1. Hold a note with a relatively pure A/B waveform.
2. Set DEPTH above 0%.
3. Pick FOLD, then change RATE.
4. Try TEMPO sync for clock-related movement.
5. Turn DEPTH back to zero to hear the unchanged carrier.

Evolution may be hard to hear on very noisy, already heavily distorted patches. Test with a simple wave and dry global FX first.

## 14. Presets, naming and saving

### Opening PRESETS

**Hold HOME for at least 1.5 seconds.** This opens a dedicated named preset list, showing up to **seven rows** at a time.

- Turn the **PRESETS encoder** to scroll through **saved presets only**.
- Scrolling **immediately loads and auditions** the chosen sound.
- Empty preset slots are skipped.
- Press **HOME briefly** to return to PLAY.

The PRESETS encoder **does not change the sound outside this browser**.

### Saving a preset

1. Leave DRAW and press **SAVE**.
2. If PROJECT SAVE is shown, rotate the **SELECT encoder** to switch to PRESET SAVE.
3. Choose the preset slot with **K1**.
4. Use **K2** to move to a character position.
5. Use **K3** to choose characters; use **K4 counter-clockwise** to erase/backspace.
6. Press **SAVE**. If the destination is already occupied, confirm the overwrite as indicated.
7. Wait for the save confirmation before switching off the instrument.

### What a preset can remember

The project and preset codecs carry the selected wave information and playable sound configuration, including morph/modulation, envelope/filter, many FX parameters and performance settings. Custom ARP and RIFF data are associated with preset slots. **Use an explicit SAVE after important changes** rather than assuming everything is automatically committed.

### Saving a waveform is separate

If you've changed the editable points in DRAW, first save the wave into a library slot. Then save the preset that uses it. This avoids accidental surprises when reusing a waveform in other presets.

## 15. ARP and RIFF mode

The ARP page offers **eight numbered modes**:

| Mode | What it does |
|---:|---|
| **0** | OFF |
| **1** | UP |
| **2** | DOWN |
| **3** | UP / DOWN (ping-pong) |
| **4** | PLAYED ORDER |
| **5** | RANDOM |
| **6** | CUSTOM programmed ARP |
| **7** | **RIFF**: scale-aware 16-step melodic generator |

### Main ARP controls

| Knob | Normal ARP modes | Mode 7: RIFF |
|---|---|---|
| **K1** | MODE | MODE = 7 |
| **K2** | RATE | RATE |
| **K3** | OCTAVE RANGE | OCTAVE RANGE |
| **K4** | TEMPO / BPM | **NEW RIFF**: turn to generate another riff |

The octave control includes upward ranges and **−1 / −2** octave options in the current source. The actual number of generated notes depends on the held keys, the octave setting and the selected mode.

### RIFF: making new musical ideas

1. First set your **key** and **scale** in HARM / GUIDE.
2. Press **ARP** until the main ARP page appears.
3. Set **K1 to mode 7 (RIFF)**.
4. Set the speed with **K2**.
5. Choose the octave range using **K3**.
6. Hold at least one keyboard note to provide a starting pitch.
7. Turn **K4** to generate a new **16-step riff** within the selected scale.
8. Save the preset when you find a riff you like.

RIFF generation uses a per-preset seed, so new variations do **not** overwrite the separate CUSTOM ARP sequence. Riffs can include pitch jumps, repetition and rests. They are generated musical patterns, not a guarantee of a specific genre or composition style.

### CUSTOM ARP editing

Press **ARP** again to reach ARP EDIT.

| Knob | Parameter |
|---|---|
| K1 | STEP |
| K2 | Held-key index / order |
| K3 | REST on/off |
| K4 | Pattern LENGTH (up to 16) |

**REC** toggles a rest at the current programmed step. SELECT can also move through steps. The custom sequence uses held-note positions across octaves rather than storing an arbitrary monophonic melody.

### ARP, sequencer and clock

When the sequencer is actively running, it takes precedence over the ARP in the current performance engine. If ARP seems silent, stop the sequencer and hold a note. The shared CLOCK editor lets you adjust the project tempo and related clock behaviour.

## 16. Sequencer and step editing

ETCH's sequencer supports patterns up to **256 steps**, with up to **eight trigger notes per step**. It also supports held-note relationships and **six parameter-lock destinations**.

### Basic sequencing

Press **SEQ** to enter or cycle the main sequencer views. PLAY/STOP starts or stops the pattern. REC enables live recording on the main sequencer editing pages.

| SEQ-page knob | Parameter |
|---|---|
| **K1** | LENGTH: 8 / 16 / 32 / 64 / 128 / 256 steps |
| **K2** | RATE |
| **K3** | SWING (0–75) |
| **K4** | GATE (5–100%) |
| **SELECT encoder** | Move through steps |

### Entering notes

On the SEQ page while transport is stopped, press keyboard notes to add or toggle triggers for the selected step. Use SELECT to move to the next step. On the NOTES page you can select and edit existing notes without deleting the rest of the step.

### Live recording

- Press **REC** in a main sequencer edit view to toggle recording.
- If needed, recording starts sequencer playback.
- Play the FM1 keyboard to add notes at the currently sounding step.
- Existing notes, HOLD links and parameter locks are preserved during overdub where possible.
- Stop recording, then use the note/step editors to refine the result.

### NOTES page

| Knob | Parameter |
|---|---|
| K1 | VOICE / selected note |
| K2 | VELOCITY |
| K3 | NOTE LENGTH |
| K4 | PITCH / NOTE |

When stopped, touching a pitch already present on the step can remove that trigger, subject to protections for linked HOLD notes. A duplicate pitch or an edit that would destroy a HOLD relationship is rejected rather than silently overwriting other notes.

### Advanced editor navigation

Within sequencer context, rotate the **ALGORITHM encoder** to cycle advanced views, including **GRID, HOLD, LOCKS, BAKE and CLOCK**.

| Editor | Purpose |
|---|---|
| **GRID** | Browse steps in pages of 16 (8 columns × 2 rows) |
| **HOLD** | Link a held note to an earlier trigger and manage sustain |
| **LOCKS** | Store step-level parameter values |
| **BAKE** | Apply harmony settings to one step or an entire pattern |
| **CLOCK** | Tempo, gate, swing and clock follow |

**GRID:** the first 16 hardware keys can select the 16 steps in the current page while transport is stopped. **REC twice** on GRID arms and then clears the currently selected step (including locks) if permitted; this is destructive. Changing the selected step cancels the armed clear.

### Step parameter locks

The six implemented lock destinations are:

1. MORPH
2. ETCH depth
3. FILTER cutoff
4. CHORUS send
5. DELAY send
6. REVERB send

On LOCKS, use **K1** to select a destination, **K2** to set its value, **K3** to switch that lock on/off, and **K4** or SELECT to move to a different step.

### BAKE and HOLD safety

BAKE uses a preview/confirmation before applying a harmony operation. HOLD links are kept separate from note attacks, so a newly triggered note can overlap an earlier sustained note of the same pitch. Some destructive edits are blocked until their HOLD relationships have been addressed.

5. MIXOLYDIAN

## 18. Motion Recording

Motion Recording captures knob movement rather than MIDI notes. V1.20 has **four lanes**:

| Knob | Recorded parameter |
|---|---|
| **K1** | MORPH |
| **K2** | ETCH depth |
| **K3** | FILTER cutoff |
| **K4** | SPACE / reverb macro |

### Access and use

1. Open **SYSTEM** through the GLO navigation and select its first tab.
2. Press **REC** to enter **MOTION**.
3. On MOTION, press **REC** to start capturing knob changes.
4. Turn any of K1–K4 during the capture window.
5. Press **REC** again to stop; playback can then loop a valid recorded clip.
6. Press **PLAY/STOP** on MOTION to toggle motion playback.

The underlying recorder stores up to **64 frames at 100 ms per frame**, or approximately **6.4 seconds**. Playback interpolates the values to avoid sharp jumps and only applies lanes that were actually moved during recording.

> Starting a fresh Motion Recording clears the previous motion clip in the current working state. Save a preset/project copy before replacing something you want to keep.

## 19. Projects and data management

### Opening PROJECTS

From PLAY, use the implemented **double short-HOME** gesture. You can also reach PROJECTS through the SYSTEM storage tab.

### What you can do

- Select one of **four** project slots, or NEW PROJECT.
- Open a selected existing project using the **SEL button**.
- Create a new project in an available slot.
- Rename project characters using the controls shown on the PROJECTS page.
- Save the current working state using the SAVE editor.

### Project save vs preset save

Press **SAVE** outside DRAW to open the save flow. The **SELECT encoder** switches between saving a **PROJECT** and a **PRESET**. In either case, use K1–K4 to select the destination and edit its name, then confirm with SAVE. Confirming an overwrite replaces the selected destination.

### Deleting a project

The PROJECTS editor implements a deliberately guarded **REC + SAVE** deletion chord, repeated to confirm. Verify the selected project before using it. Deletion is not the same as removing a preset from the list.

### Full storage and old data

ETCH checks storage capacity and record integrity when committing saves. If storage is full or an operation is rejected, the current working edit should remain available in RAM, but a completed persistent save has **not** occurred. Do not power off and assume the data was saved.

If ETCH reports **foreign storage**, it intentionally refuses automatic erasure. A separate **FX + SAVE held for five seconds** action is available on the SYSTEM/STORAGE page to initialise ETCH storage. **This destroys data in the affected storage sectors. Do not use it until you fully understand the consequences and have an independent backup.**

ETCH uses the FM1's USB-MIDI connection for musical control and firmware update communication. MIDI note-on/off, performance interaction and some clock functionality are implemented in the firmware. Close other applications holding the same MIDI port when using the installer.

In the CLOCK editor you can set:

|---|---|
| K1 | CLOCK FOLLOW: on/off |
| K2 | GATE |
| K3 | SWING |

## 21. Webinstaller, updating and recovery

### What is included

V1.20 ships with a standalone HTML webinstaller containing the experimental firmware image and an update client. The corrected V1.20 webinstaller also recognises a device already reporting `FM-1_1020` and the known loader identity `ota-FM-1_015`, with additional confirmation for direct-loader operation.

### Before any installation

1. Establish a **working, independently verified ROM-level recovery route** for your exact FM1 hardware revision.
2. Keep a verified full flash backup, and prove that it can be restored.
3. Preserve the original, legitimate stock firmware and any important user data.
4. Verify the release's expected firmware version and package checksum.
5. Read the warnings inside the actual installer before connecting or proceeding.

If those conditions are not met, **do not flash**. You can still inspect the source, run desktop tests and develop patches on a unit already running known-good ETCH firmware.

### Browser requirements

- Desktop **Chrome or Edge**, in an appropriate HTTPS/localhost context.
- A direct USB **data** cable.
- Access to Web MIDI and SysEx when the browser requests permission.
- The correct FM1 input/output pair selected in the installer.
- No DAW, MIDI monitor or other program simultaneously using that same MIDI port.

### Understanding the installer

| Stage | Meaning |
|---|---|
| VERIFY | Decode and locally validate the chosen firmware package |
| CONNECT | Choose and identify the FM1 USB-MIDI port |
| CHECK | Compare device identity and package compatibility |
| LOADER | Request or detect the expected update state |
| FLASH | Transfer the update and wait for completion |

A completed transfer **alone** does not prove that the new firmware boots. The installer is designed to check for the expected identity after reconnection before displaying success.

### Official stock restore

The installer has a separate **OFFICIAL V15** option. It requires the actual verified M-VAVE stock firmware file supplied by the user. A browser-based restore **only works when the required USB loader still responds**. It cannot repair an FM1 that no longer presents a usable loader connection.

### Safe Mode and update entry

| When | Control | What it requests |
|---|---|---|
| Power-on | **REC held** | Silent, read-only ETCH **application Safe Mode** |
| Power-on | **OCT- held** | Chip loader / UBOOT entry route |
| Normal use after audio stop | **HOME + PLAY held 1 s** | Attempt to restart audio locally, without firmware flashing |

**Safe Mode is not ROM-level recovery**, and loader availability by itself is not proof that a complete stock image can be restored. Do not promise “brick-proof” updating.

### If an update fails

- Stop making repeated blind update attempts.
- Record the **exact installer stage, message and diagnostic log**.
- Note the USB device identity visible before and after the failure.
- Do not attempt storage initialisation or random update packages as a workaround.
- Follow the verified independent recovery procedure for the specific hardware unit.

## 22. Sound-design recipes

These are suggested musical starting points, not factory presets or fixed ETCH values.

### Recipe A: Warm moving pad

1. Start with two smooth, harmonically different saved waves for A and B.
2. Set MORPH around the middle.
3. Use a relatively slow ADSR attack and release.
4. Set Wave C to **MORPH** modulation at a low rate and modest depth.
5. Add a little chorus and SPACE.
6. Try EVOLUTION in FOLD at low depth.

**Listen for:** slow movement without sharp attacks.

### Recipe B: Damaged post-punk lead

1. Choose a more angular A wave and a smoother B wave.
2. Bias MORPH towards A.
3. Add an A-side BIT or FOLD live insert.
4. Increase DRIVE carefully and trim brightness with the filter.
5. Use a short delay, then try TAPE INSTABILITY at low MIX.
6. Save a separate version before exploring high FX depths.

**Listen for:** aggression and irregular texture while preserving pitch definition.

### Recipe C: Evolving drone

1. Select waves with contrasting shapes.
2. Increase the amp release time.
3. Choose a slower Wave C modulation mode.
4. Enable EVOLUTION, try SHARP or STAIR and slowly raise DEPTH.
5. Record a movement of MORPH and SPACE on the MOTION page.
6. Save the working preset and project.

**Listen for:** subtle changes over a held note rather than a repeated pattern.

### Recipe D: Scale-aware RIFF

1. Choose a key and scale in HARM.
2. Stop the sequencer if it is running.
3. Set ARP mode **7: RIFF**.
4. Set RATE on K2 and OCTAVE RANGE on K3.
5. Hold a note in your desired register.
6. Turn K4 repeatedly to find a variation.
7. Save the preset once the riff suits your sound.

**Listen for:** phrases with meaningful repetition, rests and a consistent harmonic centre.

### Recipe E: Clean waveform comparison

1. Save two different waves in free library slots.
2. Enter DRAW for Wave A and play single notes to hear its unprocessed identity.
3. Move to Wave B and repeat.
4. Leave DRAW, open MORPH and place MORPH at 0%, 50% and 100%.
5. Disable extra modulation and wet FX while comparing.

**Listen for:** the direct difference between A, B and the interpolated carrier.

## 23. Troubleshooting

| Problem | What to check |
|---|---|
| **PRESETS encoder does nothing** | Expected outside PRESETS. Hold HOME **1.5 s**, then turn PRESETS. |
| **No presets appear** | Save a **named PRESET** first, not only a waveform or project. |
| **HOME opens PLAY instead of PRESETS** | Keep it held long enough. Avoid pressing another button during the hold. |
| **WAVE C changes don't sound different** | Raise modulation DEPTH, choose an active wave, check PHASE/MORPH target and test with dry effects. |
| **WAVE C numbers jump** | Empty physical slots may be skipped. Distinguish library slot IDs from the ordinal position among saved waves. |
| **WAVE A FX / B FX sounds dry** | Check TYPE is not OFF and MIX is above 0%. Audition each wave in its dedicated insert page. |
| **EVOLUTION sounds unchanged** | DEPTH must be above 0%. Try a simple wave with FOLD or STAIR. REC switches DEPTH between 0% and 60%. |
| **SPACE seems subtle** | Try dry notes versus short chords, compare low and high SPACE, and check the underlying REVERB settings. |
| **The display retains a moving wave after releasing a note** | Normal V1.20 behaviour is a visual release to a straight line within approximately 260 ms after the final held note. If this does not occur, record a video and your active ARP/SEQ state. |
| **Clicks with many notes** | Lower MASTER and DRIVE, reduce wet FX, test a plain eight-note patch. Hardware performance has not been fully qualified. |
| **ARP is silent** | Hold at least one key, set a nonzero ARP mode, and stop any active sequencer. |
| **RIFF doesn't change** | Be on ARP **mode 7**; K4 then regenerates the riff. Check that a note is held for playback. |
| **Sequencer stops with external MIDI clock** | Check CLOCK FOLLOW and whether your MIDI host is sending clock/transport. |
| **SAVE fails** | Check the name, destination, overwrite confirmation, storage state and capacity. Do not power off assuming the edit was saved. |
| **Foreign-storage warning** | Do not initialise casually. The explicit SYSTEM/STORAGE takeover is destructive. |
| **Browser can't detect FM1** | Use desktop Chrome/Edge over HTTPS/localhost, connect with a USB data cable, grant Web MIDI/SysEx permission and close other MIDI software. |
| **Updater reaches LOADER but does not finish** | Save the diagnostic log. Do not assume that loader detection means the device can be recovered or that flashing is safe. |
| **Audio engine reports a deadline stop** | Stop playing, save diagnostic information, and try the implemented HOME+PLAY local rearm only if the device remains responsive. |

## V1.32 — Important changes for users

**SPECTRAL:** K1 WAVE, K2 PART, K3 GAIN and K4 TILT. GAIN and TILT each show their own preset-stored value from 0–100. Edits change the actual stored waveform, not merely a graphical measurement. When SPECTRAL editing occurs while notes are still sounding, **WAIT NOTE OFF** means the audio-table rebuild is deferred. Release all held notes (including sustain/arp/sequence voices) to let the new waveform become audible. This avoids a sudden eight-voice wavetable-bank crossfade while notes are playing. The pending waveform edit is not discarded when changing screens.

**LIVING:** The real-time harmonic motion is now generated by a more economical per-voice smoothing path. DEPTH=0 remains bypass; higher DEPTH with a harmonically rich wave and COLOR away from 50 produces the strongest effect. No project conversion is necessary; PJT27 remains in use.

**AUDIO STOP:** If this warning reappears, it means the DMA safety guard detected repeated underruns. Lower FX load, stop the sequencer and capture SYSTEM > CPU/LATE diagnostics. This update reduces worst-case workload but **does not guarantee** that every polyphonic combination meets the real FM1 deadline. Do not repeatedly force restarts or flash more builds if audio becomes unstable.

**Startup plop:** Not fixed or declared safe. The diagnostic holding GLO during power-up (PC6 muted, audio initializes) is still the recommended way to isolate a potential analog-enable transient, but testing any unqualified firmware carries flash/recovery risk.

## V1.35 — POLY/MONO advanced modulation availability

In **POLY**, repeatedly press **LFO** to cycle **MOD → WAVE C FX → MOD MATRIX → MOD**. EVOLUTION, ORGANIC, SPECTRAL, LIVING and PATCH BLEND are unavailable while POLY is selected; their realtime DSP contributions are also bypassed, not merely hidden. All their patch-specific settings remain stored. In **MONO** the complete sequence is **MOD → WAVE C FX → EVOLUTION → ORGANIC → SPECTRAL → LIVING → MOD MATRIX → PATCH BLEND → MOD**.

When the synth encounters consecutive audio-deadline misses, it automatically reduces the maximum simultaneous voices from 8 to 6, then 4, 3 or 2 to protect the audio stream. After sustained healthy playback the voice allowance rises again. This is a safety fallback, not a manual polyphony setting. An actual hardware measurement is needed to validate how many voices your particular FM1 can sustain with its current FX settings.

All project/preset files stay PJT27-compatible; saving a patch in POLY does not erase hidden mono parameters. If the display reports `AUDIO STOP` again, report the note count, currently enabled FX, and any SYSTEM page `LATE`/`GUARD` counters. Repeated missed deadlines at even two voices can still trigger the protective stop. Startup pop without USB power remains under investigation.
