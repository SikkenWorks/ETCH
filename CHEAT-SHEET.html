// START

START HERE

The shortest route from power-on to a usable sound.

04 CARDS
01 / FOUNDATION

The ETCH concept

WAVE A + WAVE B create one carrier shape. MORPH moves between them. WAVE C modulates phase, morph or FX. WAVE AMP can turn a wave into audio-rate volume movement.

A + B → MORPH → FILTER / FX → AUDIO
02 / NAVIGATION

Startup & workflow

  1. Wait for the VHS intro and the SIKKENWORKS title.
  2. Choose SIMPLE or ADVANCED with K1, confirm with SEL.
  3. Change later via GLO → WORKFLOW → K2.

SIMPLE has five core pages. ADVANCED gives access to all 64 screen IDs via the WORKFLOW catalog: K3 select, K4 open.

03 / QUICK START

First sound in 60 seconds

  1. Lower MASTER, play a key and raise it gradually.
  2. HOME → SOUND: turn K1 MORPH, K2 ETCH, K3 TONE and K4 SPACE.
  3. MORPH → select Wave A/B and blend them.
  4. FILTER → refine cutoff and resonance.
  5. Save a named PRESET and wait for a success message.
04 / REMEMBER

Three things to save

WAVE64 slots
PRESET32 slots
PROJECT4 slots

A wave is a reusable drawn shape. A preset is a complete sound. A project includes working/performance/sequence data. A .etchpreset backs up the active sound, not a whole project.

02 / WAVE BLEND

MORPH: sculpt the carrier

K1WAVE A
K2WAVE B
K3MORPH
K4C RATE

Set two contrasting shapes, hold a note and sweep MORPH. The ALGORITHM encoder adjusts ETCH depth here.

03 / SHAPE & TONE

ENV + FILTER

ENVK1 Attack · K2 Decay · K3 Sustain · K4 Release
FILTERK1 Type · K2 Cutoff · K3 Resonance · K4 Drive

Short attack/release: plucks. Longer attack/release: pads and strings.

04 / MODULATION

MOD WAVE: give Wave C a job

K1Wave C source
K2DEPTH
K3RATE / ratio
K4Destination: PHASE or MORPH

SELECT switches KEYED / FREE / TEMPO. Start with low depth; high-rate modulation can become aggressive.

05 / NEW IN V1.84

WAVE AMP

Your drawn waveform becomes a repeating volume curve at oscillator speed, not a one-shot ADSR envelope.

K1 SOURCEOFF / A / B / MORPH
K2 DEPTH0–100%

At full depth: high wave = full volume, low wave = silence. Use a rounded shape for softer results. Set SOURCE OFF or DEPTH 0 to disable.

06 / MOVEMENT

ORGANIC + EVOLUTION

ORGANICDrift · Rate · Phase · Variance
EVOLUTIONDepth · Rate · Shape · Sync

ORGANIC introduces slow, smooth analogue-style drift. EVOLUTION animates the waveform (FOLD / SHARP / STAIR) without rewriting it.

Some advanced editors are MONO-only to protect FM1 performance.

07 / ROUTING

MOD MATRIX

Up to four real-time routes:

K1Route 1–4
K2Source (e.g. velocity, envelope, C, keytrack)
K3Destination: MORPH / C DEPTH / FILTER / SPACE
K4Amount −100 to +100

Set SOURCE OFF or AMOUNT 0 to disable. Aftertouch requires compatible MIDI input.

08 / CPU-AWARE EFFECTS

FX BYPASS

  1. Switch to ADVANCED and hold FX about 700 ms.
  2. K1 selects an effect.
  3. K4 or SEL toggles ON / BYP.
  4. K2 bypasses all; K3 restores all.

Heavy effect processing is skipped where supported. FX values remain unchanged. Bypass state is temporary in RAM.

// EDITING

DRAW & EDIT

Turn a blank shape into your own instrument.

04 CARDS
01 / FOUR KNOBS

DRAW: the essentials

K1XPosition
K2YDraw
K3PARTHarmonic
K4GAINHarmonic level

EDIT enters DRAW. SELECT picks A, B or C. The editor auditions the selected wave alone. Undo = ENV; Redo = LFO.

02 / FLAT LINE

Blank waveform: start fresh

  1. Enter DRAW and select Wave A, B or C.
  2. Hold EDIT for ~700 ms.
  3. Choose YES with K1; confirm with SEL.
  4. Draw from the flat zero line. ENV undoes the change.

NO is selected by default; only the chosen wave is cleared.

03 / SHAPING

Wave tools & BAKE

TOOLS offers LINE, SMOOTH, MIRROR, INVERT, NORMALIZE, FLATTEN, RANDOM, SINE, TRIANGLE, SAW, SQUARE, PHASE ROTATE and WAVE GENETICS.

From DRAW, use FX for WFX 1 → WFX 2 → SCULPT. A confirmed BAKE writes processing into editable wave points. Use Undo before saving if needed.

04 / REUSE

Library: save & load a wave

SAVEDRAW → SAVE → K1 slot · K2 position · K3 character · K4 backspace → SAVE
LOADLIBRARY → K1 slot → K2 A/B/C target → REC twice

A wave stored in the library is not the same as saving the full preset.

// RHYTHM

PLAY & PERFORM

Move from a single note to a full pattern.

05 CARDS
01 / QUICK RIFF

ARP + RIFF

  1. Choose your root and scale in HARM.
  2. Open ARP and select mode 7 (RIFF) with K1.
  3. Set rate on K2 and octave range on K3.
  4. Hold a note and turn K4 to generate a 16-step riff.
  5. Save the preset to retain it.

RIFF LAB: K1 Density · K2 Mutate · K3 Variant · K4 New Riff.

02 / RHYTHM

SEQ + live record

SEQK1 Length · K2 Rate · K3 Swing · K4 Gate
TRANSPORTPLAY/STOP to run; REC to start/stop live recording
STEP EDITStop transport; SELECT chooses step; keyboard enters note triggers

Up to 256 steps with eight triggers per step. Advanced editors: GRID, HOLD, LOCKS, BAKE, CLOCK. Destructive edits require confirmation.

03 / STAY IN KEY

HARM + SCALE GUIDE

K1Root
K2Mode / scale
K3Keylock OFF / GUIDE / LOCK
K4Chord type

GUIDE shows scale and chord information. Its NOTE control changes the displayed chord root; it does not automatically transpose the synth.

04 / LIVE PLAY

GROUPS / PERFORMANCE

GROUPSHOME + FX → split keyboard into two optional preset zones + MAIN
PERFORMANCEHOME + ARP → assign four macros and capture scenes A/B

GROUPS share the total eight-voice budget. Save a PROJECT to retain group ranges and performance scene assignments.

05 / AUTOMATION

MOTION REC

On SYSTEM → MOTION, REC starts/stops recording movement of MORPH, ETCH, CUTOFF and SPACE. PLAY/STOP toggles motion playback.

Up to ~6.4 seconds. Starting a new motion clip replaces the previous working clip.

// SAVING

SAVE & RECOVER

Protect the sounds you cannot recreate.

05 CARDS
01 / PERSISTENCE

Save a preset or project

  1. Outside DRAW, press SAVE.
  2. Choose PRESET or PROJECT with SELECT.
  3. K1 slot · K2 name position · K3 character · K4 backspace.
  4. Press SAVE, confirm overwrite if requested.
  5. Wait for the final success confirmation.
02 / .ETCHPRESET

Back up the current sound to PC

  1. Connect FM1 with a USB data cable.
  2. Open the V1.84 Project/Preset Manager in desktop Chrome or Edge.
  3. Grant MIDI/SysEx, choose FM1 and check the protocol.
  4. Read current sound → Save .etchpreset.

Works with V1.77+ live-snapshot firmware. The file includes sound/waves, not complete projects or samples.

03 / RAM IMPORT

Restore a .etchpreset

  1. Back up any currently active unsaved sound first.
  2. Use Open .etchpreset in the Manager.
  3. Stop the sequencer and release held notes.
  4. Select Send to FM1 (RAM only).
  5. Save the imported sound separately on the FM1 if you want it stored permanently.
04 / DON’T WIPE BLINDLY

STORAGE LOCKED / foreign data

Storage blocked? Keep your sound in RAM. Export it before rebooting or flashing.

At first boot, ETCH may offer to format its designated storage area. NO preserves foreign data; YES can erase previous samples in the affected sectors.

YES requires an additional confirmation and a deliberate SAVE hold for 3 seconds. Back up foreign data before taking ownership.

05 / SAFETY

Firmware and compatibility

V1.84 uses project format PJT32 and fixed firmware identity FM-1_1500. It can read PJT31; older ETCH versions may not read newly saved PJT32 projects.

Flashing, full stock recovery and cross-firmware transitions are not physically qualified by software tests alone. Verify checksums, back up your data and use a proven independent recovery procedure.

// HELP

IF SOMETHING GOES WRONG

Fast diagnosis without risky recovery guesses.

04 CARDS
01 / AUDIO

No sound / silent modulation

Check MASTER, ENV sustain, FILTER cutoff, and FX BYPASS. For Wave C, verify SOURCE, DEPTH, RATE and PHASE/MORPH destination. If POLY hides advanced editors, switch to MONO.

02 / PERFORMANCE

Clicks, pops or overload

Lower output volume, DRIVE and active FX. Test a clean patch with one note. V1.84 smooths note-on transitions, but analogue output pops are not proven eliminated.

For AUDIO STOP, review SYSTEM diagnostics; HOME + PLAY/STOP for ~1 second may locally rearm audio if responsive.

03 / STORAGE & MIDI

Cannot save / cannot connect

If saving fails: check final SAVE status and storage ownership. Do not reboot an unsaved sound. If the Manager cannot connect: use Chrome/Edge, grant SysEx, verify the cable/port, and close DAWs using the same MIDI device.
